# one-line-exit

Repo: sosissausage35-collab/one-line-exit
Owner: sosissausage35-collab
Description: The One-Line Exit — a program that writes the funniest single-line resignation letter (max 140 characters) to /output/entry.txt, for the make.fun bounty "The One-Line Exit".

## Run

```sh
node main.ts
```

This writes one line to `/output/entry.txt` (absolute path, UTF-8, deterministic).
